# React + TypeScript + Vite

Want to add a cover to the e-book, but not sure how to create the image?

You can use this small tool to quickly create the cover for the e-books you need.

📚 First, download the project to the local machine.

🚀 After pulling the code, you can use the command `pnpm run dev` to start the project.
